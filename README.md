\# Resume Analyzer \& Job Match System



A full-stack web application that analyzes a user's resume and compares its skills with a given job description.



The system identifies matching and missing skills, calculates a job-match percentage, provides skill-gap suggestions, recommends suitable job roles, and stores previous analyses for future reference.



\## Features



\- Upload and analyze a resume PDF

\- Extract resume information such as name, email, and phone number

\- Detect technical skills from the resume

\- Enter and analyze a job description

\- Compare resume skills with required job skills

\- Calculate job-match percentage

\- Display matched and missing skills

\- Identify skill gaps

\- Provide improvement suggestions

\- Calculate a resume score

\- Recommend suitable job roles

\- Store analysis results in MongoDB

\- View recent analysis history

\- Reset the analysis and start again

\- Basic error handling and input validation
